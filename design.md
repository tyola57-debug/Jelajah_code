# Ethereal Logic Design System
 
## Brand Identity
**Name:** Visionary Architect
**Industry:** IT Solutions & Web Development
**Personality:** Futuristic, Professional, Innovative, Precise

## Design Principles
1. **High Contrast**: Dark surfaces with vibrant neon accents to guide attention.
2. **Visual Depth**: Use of glassmorphism, subtle shadows, and blurs to create layering.
3. **Typography-First**: Clean sans-serif typography with generous spacing for readability.
4. **Motion-Ready**: Layouts designed for smooth transitions and interactive feedback.

## Visual Language

### Color Palette
- **Primary (Core Purple)**: `#6d28d9` (Vibrant Violet) - Used for primary actions, active states, and highlights.
- **Secondary (Deep Space)**: `#131b2e` - Used for containers and secondary surfaces.
- **Surface (Background)**: `#0b1326` - Deep navy background for high-contrast dark mode.
- **Accents (Gradient)**: Gradations from Primary Purple to Tertiary Cyan for a "high-tech" glow.

### Typography
- **Headlines**: **Montserrat** (Bold/ExtraBold) - Strong, geometric character.
- **Body**: **Montserrat** (Regular/Medium) - Versatile and highly legible.
- **Type Scale**:
  - Display: 48px/64px (Hero headlines)
  - Headline: 32px/40px (Section titles)
  - Title: 20px/28px (Card titles)
  - Body: 16px/24px (Standard reading)

### Layout & Spacing
- **Container**: Max width 1280px with responsive margins.
- **Grid**: 12-column flexible grid.
- **Spacing System**: Base 4px scale (4, 8, 16, 24, 32, 48, 64, 80).
- **Radius**: `ROUND_EIGHT` (8px) for cards and buttons to maintain a modern, slightly rounded look.

### Components
- **TopNavBar**: Sticky, glassmorphism effect (`backdrop-blur-3xl`), gradient brand logo.
- **Primary Button**: Solid gradient background, white text, hover lift effect.
- **Secondary Button**: Outlined or subtle background, hover glow.
- **Cards**: Surface-container-low background with subtle borders and hover scaling.

## Voice & Tone
- **Professional but Approachable**: Use "Kami" (We) to build trust.
- **Direct**: Clear value propositions and transparent processes.
- **Forward-Looking**: Language that emphasizes "Membangun masa depan" (Building the future).
