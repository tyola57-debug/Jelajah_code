# Project
Website Company Profile untuk jasa pembuatan website profesional.

## Objective
Membuat website modern, cepat, responsive, dan profesional yang mampu meningkatkan kepercayaan calon klien serta mengarahkan mereka untuk menghubungi melalui WhatsApp.

---

# Target User

- UMKM
- Perusahaan
- Sekolah
- Yayasan
- Organisasi
- Event Organizer
- Personal Brand
- Startup

---

# Design Goal

Website harus memberikan kesan:

- Profesional
- Modern
- Bersih
- Cepat
- Premium
- Mudah dipahami
- Fokus pada konversi

Hindari desain yang ramai, terlalu banyak animasi, atau elemen yang mengganggu.

# Image Rules

Semua screenshot:

- Resolusi tinggi
- Tidak blur
- Konsisten
- Rasio seragam
- Menggunakan mockup bila perlu

---

# Animation

Gunakan seperlunya.

Contoh:

- Fade Up
- Fade In
- Hover Card
- Button Hover
- Smooth Scroll

Hindari:

- Animasi berlebihan
- Parallax berat
- Efek yang mengurangi performa

---

# Performance Rules

Selalu prioritaskan:

- Lazy Load Image
- Responsive Image
- Minified Asset
- Semantic HTML
- Accessibility
- SEO
- Lighthouse Score tinggi

Website harus ringan.

---

# Responsive

Breakpoint:

Mobile

Tablet

Desktop

Semua section harus tetap nyaman digunakan.

---

# Coding Rules

- Clean Code
- Component Based
- Mudah dikembangkan
- Nama class konsisten
- Hindari duplikasi kode
- Struktur folder rapi

---

# SEO

Setiap halaman harus memiliki:

- Title
- Meta Description
- Open Graph
- Structured Data bila diperlukan
- Alt Image

---

# CTA Rules

Setiap section penting boleh memiliki CTA menuju WhatsApp.

Prioritas CTA:

# WhatsApp

CTA:

---

# Portfolio Rules

Portfolio harus menjadi fokus utama website.

Gunakan:

- Screenshot besar
- Deskripsi singkat
- Tech Stack
- Fitur utama
- Detail Project

---

# Writing Style

Gunakan bahasa:

- Profesional
- Singkat
- Mudah dipahami
- Tidak bertele-tele
- Berorientasi pada manfaat bagi calon klien

---

# Do Not

- Jangan menggunakan lorem ipsum.
- Jangan memakai gambar stok yang tidak relevan.
- Jangan menampilkan informasi palsu.
- Jangan membuat testimoni fiktif.
- Jangan membuat desain terlalu penuh.
- Jangan menggunakan warna yang bertabrakan.
- Jangan mengorbankan performa demi animasi.

---

# Final Goal

Website harus membuat pengunjung:

1. Percaya terhadap kualitas jasa.
2. Melihat portofolio dengan mudah.
3. Memahami layanan yang tersedia.
4. Tertarik menghubungi melalui WhatsApp.
5. Mendapat pengalaman yang cepat, nyaman, dan profesional di semua perangkat.
